01

粘贴链接，获得笔记

你每天刷 B 站，复制一个链接，一条命令——然后呢？让我们打开快递分拣中心的大门，看看包裹在各个站点之间经历了什么。

你只需要一行命令

想象你走进一家快递分拣中心。你只需要把包裹（视频链接）递给前台，说一句暗号。剩下的，分拣中心的机器全部搞定。

在 Bilibili Notes 里，这句"暗号"就是下面这一行命令：

终端 uv run python scripts/pipeline.py --bv BV1ABcsztEcY
逐词翻译
uv run — 用 uv 工具运行（自动装好依赖）
python scripts/pipeline.py — 执行流水线脚本
--bv — 指定输入模式为 BV号
BV1ABcsztEcY — 这个视频的 BV 号（影视飓风的一期视频）
ℹ️
什么是 CLI？

CLI（命令行界面）就是你跟程序对话的窗口。你输入一行文字，程序回复一行结果。没有按钮，没有界面——只有文字。这行命令就是你对"分拣中心"发出的第一张工单。

按回车之后，程序开始干活。它不会问你任何问题——你只需要等。

📦
源码一瞥：流水线入口

以下是 scripts/pipeline.py 的核心函数签名。不用读懂每一行——只需看到它接收一个 BV 号，然后返回一个文件路径（生成的笔记）：

Python def process_single(bvid: str, config: dict, ...) -> Path: notes_dir, images_dir = get_vault_paths(config) # 检查是否已有笔记（跳过重复工作） existing = notes_dir.glob(f"*({bvid}).md") if existing: return existing # 已有就直接返回 # 1. 获取数据 → 2. 转录 → 3. 抽帧 # → 4. 分析 → 5. 生成笔记 ...
白话翻译
process_single — 处理一个视频的主函数
bvid — 传入的 BV 号（你的"快递单号"）
get_vault_paths — 找到 Obsidian 笔记库存放位置
existing check — 先查查这个快递是否已经处理过
5 个步骤 — 按顺序走完整个分拣流水线

接下来，让我们跟着这个包裹，一站一站地走完整个流程。

幕后发生了什么

你的包裹（BV 号）进入分拣中心后，会经过 5 个站点。每个站点都有专门的"工人"负责一道工序。点击"下一步"，跟着包裹走一遍。

点击"下一步"，开始跟踪包裹旅程
Step 0 / 5

整个流程用一句话概括：

1
抓取数据

DataFetcher 去 B 站服务器拉取视频信息、字幕、评论和音频——就像分拣员从包裹上取下所有快递单据。

2
抽取关键帧 + 转录音频

FrameExtractor 从视频中均匀截取最有代表性的画面。Whisper 把音频听写成文字——两个工序可以同时进行。

3
AI 分析 + 生成笔记

视觉模型逐张分析关键帧内容。NoteGenerator 把字幕、转录、帧描述、评论全部汇总，交给 LLM 生成最终笔记。

4
存入 Obsidian

生成的 Markdown 文件直接保存到你的 Obsidian vault 中——打开 Obsidian 就能看到。

📦
快递中心比喻

你投入一个包裹（BV 号）→ 前台登记（Pipeline 接单）→ 取件员拆箱提取信息（DataFetcher）→ 质检员拍照 + 听写（FrameExtractor + Whisper）→ 包装师分类整理贴标签（NoteGenerator + LLM）→ 投递到你的邮箱（Obsidian vault）。

产出的笔记长什么样

包裹投递完毕。你打开 Obsidian，会看到一份这样的笔记——不是一堆乱码，而是一个结构清晰、图文并茂的知识卡片。

🏷️
Frontmatter 元数据

标题、BV号、UP主、时长、链接、日期、标签——笔记的"身份证"

📝
概要 Summary

AI 自动生成的一段话，概括视频的核心内容。相当于快递单上的"物品摘要"。

📷
关键帧 Keyframes

从视频中截取的代表性画面，每张配有 AI 生成的描述文字。相当于包裹里的实物照片。

📖
详细笔记 Notes

按主题分段整理的笔记，来源是字幕或 Whisper 转录文本。每段有小标题和要点。

💬
精选评论 Comments

从评论区抓取的热门评论。相当于其他"收件人"对这个包裹的评价。

📋
